## Changes

- **Audio workload:** use one orchestration instrument per written track, fewer oscillator layers/partials, and remove per-note chorus, vibrato, tremolo and noise layers. Melodies and written rhythmic events remain, but the arrangement is intentionally lighter. Boss phase-two stinger/riser behavior remains. Fade and then cancel old song voices as a group, including their effect sends, without stopping the next song or SFX.
- **Audio transitions:** suspend hidden-tab audio and resume the same context on return. A quick hide/show race now resumes even if suspension finishes after the visible event. Ambient one-shots are skipped while hidden/suspended so they cannot pile up on the frozen clock. Existing gesture recovery, device-output diagnostics, bounded upload retries and the manual Recover Audio / Download Error Logs controls remain.
- **Hiss:** hat/ride/shaker levels are reduced to 35%, crashes to 60%; high-frequency music filtering and shelf boost are softened. Lobby high-frequency ambience and boss rain are quieter. This changes the mix and needs listening acceptance, not just counters.
- **Menu:** move “Sandy’s” upward six pixels. Local Best uses unpadded numbers, tabular typography and a level plaque without the heavy number shadow. X/GitHub destinations are unchanged.
- **Floor Select:** show floors in ascending order; clicking previews a floor, with an explicit Play Floor button. Remove the decorative tower and misleading music “SCORE” label. Show the objective, practice loadout explanation and how to enter campaign rankings. Keyboard order matches the list; narrow screens stack and scroll.
- **Scoreboard:** refresh every 60 seconds while visible, plus explicit refresh/open/focus. Show campaign progress and score. New Game results can be signed after defeat or victory, ordered by floors completed, then score, then earlier submission. COMPLETE outranks reaching Floor 6. This follows the stated working assumption about unfinished campaigns; quitting without submitting does not automatically post a result. Floor Select and retry after defeat are practice. Existing completed-only records migrate as completed campaigns; malformed state remains protected.
- **Mouse:** clear raw and smoothed movement when pointer lock or window focus changes; discard the first recapture mouse event to prevent cursor-warp jumps. Capturing the mouse cannot also fire the weapon. Pointer-lock request failures now log their error name/message and focus state instead of disappearing silently.
- **Sprayer:** correct the nozzle anchor, attach and orient the mist there every frame, account for the different world/viewmodel camera lenses, and start visible paint at that projected nozzle. Use small paint droplets and feathered mist instead of oversized flashes and long tracers. The visual offset converges to the existing projectile path; collision origin, damage and spread stay unchanged.
- **Boss:** increase base damage from 11.5 to 15. Add two paint cans in open final-floor lanes: 9 → 11 cans, up to 28 additional paint. Boss health, cooldown and other map geometry are unchanged.

## Reproduce and package

Run the normal build, `test:scoreboard`, `test:leaderboard-client`, `test:audio-health`, `validate:levels` and `check:classic`. Start the same-origin server with temporary `TQ_DATA_FILE` and `TQ_TELEMETRY_FILE` paths on port 4178, then run:

```sh
node tools/followup_sanity.mjs http://127.0.0.1:4178/ /tmp/tq-followup
node tools/followup_gameplay_sanity.mjs http://127.0.0.1:4178/ /tmp/tq-followup-gameplay
node tools/audio_incident_sanity.mjs http://127.0.0.1:4178/ /tmp/tq-audio-diagnostics
node tools/sanity.mjs http://127.0.0.1:4178/ /tmp/tq-regressions
```

`TQ_SOAK_SECONDS=1` is only a quick UI/alignment rerun of the gameplay script; its default 90 seconds supplies the concurrent active measurement. Raw test downloads and logs should stay private.

The refreshed runtime archive contains only `dist/` and `server/`. Deployment continues to use [ZO_DEPLOYMENT.md](ZO_DEPLOYMENT.md), with persistent data outside the release directory. Runtime hashes are recorded in the local artifact manifest next to the archive.
